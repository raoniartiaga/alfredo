Alfredo - Privacy Policy

Last updated: November 17, 2026

Who uses this app

Alfredo is a private personal assistant used only by its owner, Raoni Artiaga. Only the owner's own Google account is connected.

Data accessed

With the owner's consent, Alfredo accesses the owner's Gmail messages (read-only), and may send email or edit specific files on the owner's behalf when the owner requests it.

How data is used

Data is used only to provide features to the owner, such as reminders, summaries and alerts. It is not sold, not used for advertising, and not shared with third parties, except for the AI service providers that process requests on the owner's behalf.

Storage and security

Data is kept on a private server controlled by the owner. Access credentials are stored with restricted permissions.

Google API Services User Data Policy

Alfredo's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
